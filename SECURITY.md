# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in CivicPay Open Framework, please report it responsibly by opening a private security advisory on GitHub, or emailing the maintainers. Do not open a public issue for security vulnerabilities.

## Production-use disclaimer

CivicPay Open Framework is a **reference implementation using synthetic data**. It is:

- **NOT** production-ready,
- **NOT** Reg E / BSA / AML compliance advice,
- **NOT** a SOC 2 control,
- and **must NOT** be used with real personally identifiable information (PII) without an institution-specific security and compliance review.

Before any operational use, an institution must perform its own security review covering: data classification, access controls, encryption at rest and in transit, secret management, and regulatory applicability (Reg E, BSA/AML, GLBA, state data-protection laws). The Framework provides no such controls out of the box.

## Supported versions

Only the latest released version receives security updates.
